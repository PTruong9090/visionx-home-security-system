# Architecture Decision Records

Each ADR records one significant architectural decision: the context at the time, what was
decided, why, and what was rejected. They are written to be read later, when the reasoning
has been forgotten or when a decision needs revisiting.

ADRs are append-only. If a decision changes, write a new ADR and mark the old one
`Superseded by NNNN` rather than editing it. The record of what we thought at the time is
the point.
